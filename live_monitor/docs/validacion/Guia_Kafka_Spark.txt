======================================================================
ERRORES Y ESPERAS
======================================================================
- Si aparece >> en PowerShell, puede faltar cerrar comillas o paréntesis.
  Si aún no se ejecutó el comando, Ctrl+C cancela la entrada incompleta;
  luego copiar otra vez la línea completa de esta guía.
- Si Docker muestra «Container ... Creating» en rojo al usar 2>&1,
  revisar el JSON final y el código de salida. Ese texto por sí solo no
  demuestra que el proceso haya fallado. No ignorar tracebacks reales.
- Si falla un comando, guardar la salida y detener la secuencia.
- Si el dashboard tarda, repetir consultas de lectura, no publicaciones.
- Una conexión rechazada al dashboard requiere comprobar servicios/logs;
  no se soluciona borrando volúmenes.
- Los 20 o 30 segundos son esperas orientativas, no garantías de latencia.
